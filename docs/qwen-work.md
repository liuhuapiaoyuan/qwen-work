## 视口

2026-10-22 用 320、390 和 1440 宽复查。页面本身没有横向滚动。

- 窄于 640：官网收成菜单；工作台边栏收成抽屉，点遮罩、关闭或进入其他页面后收回。顶栏只留「反馈」和积分。
- 640 及以上：工作台边栏常驻，可以折叠。顶栏显示「下载桌面版」和「问题反馈」。官网导航从 768 起展开。
- 定价对比表、能力卡片、产物筛选、技能分类在窄屏里横向滑动。
- 登录卡在短屏可以整页滚动，顶部不会被裁掉。
- 新人积分提示在手机上排在内容前面，在桌面停在右上角。

## 仍需处理

1. 刷新或重新打开页面后，安装、上传、定时任务、对话和密码都会清空。
2. 对话不会调用千问模型，产物也不是可下载的真实文件。
3. 积分充值没有阿里云价格和支付结果。
4. 网页版账号页本身没有「修改密码」；本地这一项只服务演示。
5. 官网不是整页像素还原，社交账号和外链「千问AI平台」还缺地址。
6. 帮助文档的具体文章、HarmonyOS / Linux 安装包地址没有单独采集。
7. 专家套件和技能图标、完整简介没有落地。

## 复测

```bash
npm run dev
```

建议按这条顺序点一遍：

1. `/signin`：勾选协议，用 `13800138000` 和 `246810` 登录。
2. `/app`：点一条提示并发送，确认进入对话且右侧出现任务监控。
3. 技能页点「查看全部」，再点下一页。
4. 专家套件和连接器各安装一项，再打开详情卸载。
5. 定时任务新建一条，产物页上传一个文件并收藏。
6. IM 频道保存钉钉配置。
7. 设置里切换暗色，个人中心修改昵称和密码。
8. 价格页订阅标准版，回到积分页确认充值按钮可点。
